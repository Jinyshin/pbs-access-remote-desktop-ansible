# PBS · Access · Remote Desktop Ansible

PBS·Access 및 원격데스크톱 환경의 설치·설정을 자동화합니다.

## 구성 범위

- 공통: 설치본 저장소용 NFS 연결
- PBS: Server·실행 노드 설치 및 설정
- Access: 서버·실행 노드 구성요소 설치 및 설정
- 원격데스크톱: GPU 드라이버·데스크톱 환경 구성 및 Dock 등 화면 설정

## 환경 설정

- 서버 주소·NFS 경로·설치 버전 등은 환경변수 또는 외부 설정으로 지정
- SSH 개인키는 저장소 외부의 로컬 파일 사용
- 제품 설치본은 지정한 NFS에서 제공
- 실제 환경 설정·인증정보·설치본·라이선스 파일은 Git 관리에서 제외
